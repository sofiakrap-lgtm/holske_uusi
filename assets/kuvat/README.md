# Kuvat

Lisää tähän kansioon sivuston valokuvat. Käytä kuvaavia nimiä pienillä kirjaimilla ja väliviivoilla, esim.
`kattomaalaus-omakotitalo-vantaa.jpg`.

- Vähintään 2000 px leveitä, JPG tai PNG. Sivusto pakkaa ne automaattisesti WebP/AVIF-muotoon.
- Ei tekstiä kuvan päällä.
- Lista kuvista, joita sivusto tarvitsee, löytyy README:stä kohdasta "Kuvat".
