# Logot ja grafiikat

Lisää tähän kansioon Holsken logot ja muut graafiset elementit (SVG ensisijaisesti, muuten PNG).

Sivusto käyttää näitä tiedostoja (nimeä samoin, niin vaihto on helppo):
- `logo.svg`: päälogo (header)
- `logo-valkoinen.svg`: logo tummalle taustalle (footer)
- `favicon.svg`: selaimen välilehden ikoni

Kun olet vaihtanut tiedoston, kopioi se myös kansioon `public/` tai `src/assets/` (ohje README:ssä).
