# Logot ja grafiikat

- `logo.svg`: päälogo, sivuston käyttämä versio. Väri tulee sivulta (currentColor), joten sitä ei tarvitse tallentaa eri väreissä.
- `logo-pieni.svg`: pieni H.-logo, josta favicon tehdään.
- `päälogo, holske.svg` ja `holske pieni.svg`: alkuperäiset tiedostot (valkoiset).

Kun vaihdat logon, aja `node scripts/luo-grafiikat.mjs`.
