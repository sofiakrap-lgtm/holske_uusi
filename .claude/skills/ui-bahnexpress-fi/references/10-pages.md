## 10.2 Jokaisen sivupohjan osiojärjestys
Teema suluissa.

**A Asiakaslanding**
1. Hero (birch + media): H1 3 riviä, hintalomake (2 kenttää + notch + xl-nappi), tumma hero strip 3 lupauksella (asphalt overlay).
2. Käyttötapaukset (light-grey): section header + käyttötapausrata (6 korttia, laajenevat).
3. Laskuri (teal): section header + kaksi paneelia notch joinilla.
4. Tuote (asphalt): section header + desktop-ruutukaappaus + välilehdet/karuselli kuvateksteillä.
5. Asiakkaat (birch + kartta): kartta taustana, lainauspinnit, snap-karuselli lainauksista.
6. Tarinat (light-grey): karuselli horisontaalikortteja + tertiary-nappi "kaikki".
7. FAQ (green): otsikko + CTA vasemmalla, accordion l oikealla.
8. Yhteystiedot (birch): kontaktikortit, korostettu kortti.
9. CTA (asphalt): display-kysymys + primary s.

**B Kohderyhmälanding** (kuljettajat)
1. Hero (birch + media): H1, CTA-napit, stat-strip (3 rullaavaa lukua).
2. Logot (asphalt): subsection header + logo grid.
3. Päivä (light-grey): karuselli m-kortteja landscape-thumbnaileilla + sivuindikaattori.
4. Sovellus (asphalt): rail-karuselli mobiiliruutukaappauksista + indikaattori.
5. Ansiolaskuri (teal): segmented-valinta + input-rivit + sliderit + tulos.
6. Vaiheet (asphalt): proosa + aikajana l (bleed end) + feature grid.
7. Kartta + lainaukset (birch).
8. Miksi (light-grey): video-thumbnail + quote block l.
9. FAQ (green), 10. Yhteystiedot (birch, stacked kortit), 11. CTA (asphalt).
Kuljetusliikkeet-variantti: hero (hero strip), feature grid l (light-grey), kartta + taulukko snap-karusellissa (birch), aikajana (asphalt), FAQ (green), yhteystiedot (birch), CTA (asphalt).

**C Tietoa**: section header + video-thumbnail radius-l + proosa + logo grid (birch) · quote-osio (light-grey) · tarinakarusellit (birch) · yhteyshenkilöt (light-grey).

**D Ura**: hero + stat-strip (birch) · avoimet tehtävät korttigridissä (light-grey) · feature grid "mitä odottaa" (birch) · proosa + pystysuora yksinkertainen aikajana (asphalt) · tarinakaruselli (light-grey).

**E Tarina**: caption-1 + display-wide-3 H1 + video-thumbnail radius-l + quote xl (birch) · ingressi body-2 · proosaosiot heading-wide-3 + body-2 · "lisää tarinoita" karuselli portrait-thumbnail-korteilla (light-grey).

**F Tekstisivu**: section header + proosa, otsikkoparit (birch).

## 10.3 Toistuvat osiokaavat
- Sivu päättyy aina: FAQ (green) → yhteystiedot (birch) → CTA (asphalt) → footer (birch).
- Hero on aina birch-teema median päällä, ja sen alla tumma hero strip.
- Section header aina keskitetty: display H2 + alaotsikko.
- Teemat eivät toistu peräkkäin (paitsi kun toinen on kuvallinen backdrop).
